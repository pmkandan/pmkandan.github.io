TVAlertAnalyzer - Privacy policy

Last updated: 16 November 2026

TVAlertAnalyzer is a private tool used only by its owner, on the owner's own Google account.

Data accessed

Read-only access to the owner's Gmail (scope gmail.readonly) to read TradingView alert emails and broker contract-note emails. The tool never sends, deletes, labels or modifies email.

Use and storage

Data is processed and stored only on the owner's own computer for personal portfolio tracking. It is not shared with, sold to or transferred to any third party, and it is not used for advertising.

Google API data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
